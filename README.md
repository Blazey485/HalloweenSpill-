# HalloweenSpill

Idee 
1. mord i kanitana

2. heks i bakbygget som lager kolombiansk sukker

3. en kar går rundt og samler spøkelser som  luigi mansion 



* Ideen er som garfild scary scavenger spill, hvor du kan gå rundt på mappet, og finne hints/clues for å finne et passord
   passordet finner du ved å løse gåtene som er rundt om kring i mappet.
